# WorksManagerMini - Internal Management System

A simple and efficient Internal Management System built with ASP.NET Core for managing internal works, tasks, and operations.

## 🚀 Features
- User Authentication & Authorization
- Work / Task Management
- Dashboard with status tracking
- Role-based access
- Clean and responsive UI

## 🛠️ Tech Stack
- **Backend:** ASP.NET Core MVC / .NET 8
- **Frontend:** Razor Views, Bootstrap, JavaScript
- **Database:** SQL Server / Entity Framework Core
- **IDE:** Visual Studio 2022

## 📂 Project Structure
- `WorksManagerMini` - Main web application
- `WorksManagerMini.slnx` - Solution file

## ⚙️ How to Run
1. Clone the repo:
2. Open `WorksManagerMini.slnx` in Visual Studio
3. Restore NuGet packages
4. Update connection string in `appsettings.json`
5. Run migration (if needed):
6. 6. Press F5 to run!
